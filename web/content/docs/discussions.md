GitHub Discussions is not enabled for the SkillIssues repository yet. Until it is, use GitHub issues for questions, ideas and conversation.

## Where to go

- **A question about how something works.** Check the [FAQ](/docs/faq) and [How it works](/docs/how-it-works) first. If they don't answer it, [open an issue](https://github.com/dizziedbliss/SkillIssues/issues/new).
- **Something is broken.** See [Report a bug](/docs/report-a-bug).
- **An idea.** See [Request a feature](/docs/request-a-feature).
- **A repository is missing.** See [Suggest a repository](/docs/suggest-a-repository).
- **A security problem.** Don't post it publicly. See [Security](/docs/security).

## Ground rules

Be kind, assume good intent, and follow the [Code of Conduct](https://github.com/dizziedbliss/SkillIssues/blob/main/CODE_OF_CONDUCT.md). Search the existing issues before you open a new one, and add to a thread if your question is already there.

When Discussions is turned on, this page will point to it.
