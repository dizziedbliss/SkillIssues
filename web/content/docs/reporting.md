## What you can report

You need to be signed in to report. Each report is about one thing, for one reason.

| What | From | Reasons |
|---|---|---|
| An issue | **Report this issue** on its page | Spam or advertising; abusive; already fixed, or a pull request already solves it; not really an issue (a question, a support request, a duplicate); the difficulty is wrong; something else. |
| A repository | **Report this repository** on any of its issues' pages | Spam; malware or something unsafe; abandoned, so nobody will review a contribution; something else. |
| A shared theme | **Report** in **Settings → Themes → Community** or **Shared with you** | Abusive; pretends to be something it isn't; broken or unreadable; something else. |

You can add a note of up to 500 characters. Don't put private details in it.

## What happens to a report

- **It's private.** Only the people who run SkillIssues see reports. Nobody else, including the person or project you reported, sees who reported what. Nothing about reports is shown on the page.
- **Enough reports hide it.** When three different people report the same thing, it leaves the catalog, search, and the community themes until someone has looked. Its own page still opens. The number is a setting, so it can change.
- **Then someone decides.**
  - **Upheld:** an issue stays hidden, a repository is removed from the catalog, and a theme is made private, which takes it off everyone else's account.
  - **Dismissed:** it comes back.
- **One report per thing.** You can report the same thing again once your earlier report has been dealt with. To stop the system being flooded, one person can make up to 20 reports a day.

Reports are kept with your account, and deleting your account deletes them.

## Bugs in SkillIssues itself

A report is about the catalog's content. If SkillIssues itself is broken, open an issue on GitHub instead. See [Report a bug](/docs/report-a-bug). For a security problem, see [Security](/security), and don't post it in public.

## Maintainers

If you'd rather your repository wasn't listed, you don't need to report it: [ask for it to be excluded](https://github.com/dizziedbliss/SkillIssues/issues/new?template=exclude_repository.yml). See [For maintainers](/maintainers).
