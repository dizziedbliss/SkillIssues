## SkillIssues

SkillIssues is released under the MIT License. The full text is in the [LICENSE file](https://github.com/dizziedbliss/SkillIssues/blob/main/LICENSE) of the [source repository](https://github.com/dizziedbliss/SkillIssues).

## Data

- **GitHub.** Issue and repository data comes from GitHub's public API. Issues and their content belong to their authors, and each repository keeps its own license.
- **GH Archive.** Hourly public events come from [GH Archive](https://www.gharchive.org), which records the public GitHub event stream.
- **Kaggle.** The initial repository metadata came from the Kaggle dataset "GitHub repository metadata with 5 stars". That dataset is the starting list of repositories. Their current details and issues are read from GitHub.

## Software

SkillIssues is built on open-source software, each piece under its own license. The dependencies are listed in the repository's package manifests (`package.json` and `go.mod`), and the licenses of each are in the dependencies' own repositories.
