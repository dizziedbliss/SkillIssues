SkillIssues is run by one maintainer and has no support email address. The quickest way to reach us is on GitHub.

## Pick the right route

| You want to | Go here |
|---|---|
| Report something broken | [Report a bug](/docs/report-a-bug) |
| Suggest an improvement | [Request a feature](/docs/request-a-feature) |
| Ask a question or start a conversation | [Open an issue](https://github.com/dizziedbliss/SkillIssues/issues/new). See also [Discussions](/docs/discussions). |
| Get a repository listed, or removed | [Suggest a repository](/docs/suggest-a-repository) and [For maintainers](/docs/for-maintainers) |
| Ask us to delete your account or data | [Open an issue](https://github.com/dizziedbliss/SkillIssues/issues/new). Don't include private details. See [Privacy policy](/docs/privacy). |
| Report a security problem | Privately. See [Security](/docs/security). |

## Before you write

- Search the [existing issues](https://github.com/dizziedbliss/SkillIssues/issues). Your question may already have an answer.
- Check the [FAQ](/docs/faq).
- Everything you post in a GitHub issue is public. Never include a token, a password or anything private.

## Security problems

Don't post a vulnerability in a public issue. Contact [@dizziedbliss](https://github.com/dizziedbliss) privately on GitHub. [Security](/docs/security) says what to include.
