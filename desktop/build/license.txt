SkillIssues: license and terms
==============================

Please read this before installing.

What SkillIssues is
-------------------
SkillIssues helps you find open-source issues you can solve, and takes you from
reading an issue to a pull request. The app forks a project to your GitHub
account, clones your fork into a folder you choose, makes a branch, and opens it
in VS Code. You commit, push and open the pull request from the app.

Your GitHub token for pushing stays on this computer, encrypted by your system
(or held in memory only, where it can't encrypt it). It is never sent to
SkillIssues. Signing in to SkillIssues only reads your GitHub id, username and
avatar.
